# Lab02CarritoKotlin

## Descripcion
Aplicacion de carrito de compras desarrollada en Kotlin para el laboratorio de la Semana 03.

## Funcionalidades

- Se añadio 2 modos: Cliente y Administrador
- Se añadio metodo de compra por cuotas

## Resultado

La aplicacion muestra en consola el cliente sus cuotas y el sistema le pregunta si quiere pagarlas.
