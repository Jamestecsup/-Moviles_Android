# Lab02CarritoKotlin (Con IA)

## Descripcion

Este laboratorio implementa un carrito de compras utilizando Kotlin y Programacion Orientada a Objetos (POO) con apoyo de Inteligencia Artificial.

## POO

Se implementaron clases para representar los productos y el carrito de compras.

Se aplicaron conceptos de encapsulamiento, herencia y polimorfismo.

## Ejecucion

El programa se ejecuta mediante el modulo Carritolib y muestra los resultados del carrito en consola.
